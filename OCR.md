Локальный Algoritmi использует PaddleOCR (RapidOCR, PP-OCRv5 eslav) и Tesseract независимо. При расхождениях, отсутствии строки, низкой уверенности или отказе основного движка подключается EasyOCR. Третьему движку по возможности передаются только спорные области.

Совпасть должны предмет и оценка. Два независимых совпадения с уверенностью каждого от 0,75 дают автоматическую отметку. При отсутствии кворума оценка остаётся пустой и среднее не публикуется. Варианты OCR доступны в существующей подсказке строки. Совпадение моделей не является гарантией безошибочности или полноты списка.

Средний балл согласованных оценок появляется сразу в существующих карточках и выгрузке. Если два независимых OCR согласовали оценки, категорию, серию и непустой номер, документ принимается автоматически без оператора. При расхождении реквизитов нужна их сверка. Правка оценки или списка предметов снимает автоматическое подтверждение и требует существующей кнопки подтверждения проверки документа.

Для запуска в Windows:

```powershell
.\start.ps1
# Другой свободный порт:
.\start.ps1 -Port 8770
```

Окружение трёх OCR — `.ocr-venv`, модели — `.ocr-models`. Существующая `.venv` сохранена. Для переустановки на другом компьютере нужны Python 3.12 и Node.js; выполните `setup_ocr.ps1`. Интернет используется только при подготовке зависимостей и весов. Во время распознавания автоматическая загрузка весов отключена, документы остаются на компьютере.

Тройная проверка работает через `server.py`. Автономная статическая сборка `dist` работает без Python и использует один Tesseract.js: её оценки требуют ручной сверки, автоматическое согласие двух OCR в ней не имитируется. HTML, CSS, шрифты и графика исходного сайта не изменялись.

Проверки:

```powershell
.\.ocr-venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p 'test_*.py'
npm test
```

Ускорение: модели остаются загруженными до остановки сервера; Tesseract читает до двух страниц параллельно, дополнительное изображение готовится только для повторного чтения заголовка. Разрешение PDF сохранено (до 300 dpi). После обновления перезапустите server.py. Это ускорение относится к локальному режиму.
