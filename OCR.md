Локальный Algoritmi сначала запускает Tesseract. Если он уверенно разобрал таблицу, другие OCR не запускаются. Иначе подключается PaddleOCR (RapidOCR, PP-OCRv5 eslav), а для спорных страниц — EasyOCR. Третьему движку передаются только спорные области; если первые два OCR уже прочитали числовую оценку, он проверяет строку напрямую без повторного поиска текста. Docling анализирует структуру только маленьких или нераспознанных таблиц (не более четырёх страниц за документ). Его предложения требуют ручной сверки и не считаются самостоятельным подтверждением оценки.

Строка принимается автоматически, если хотя бы один OCR прочитал предмет и оценку с уверенностью от 80%, а другой столь же уверенный OCR ему не противоречит. Дополнительные OCR пропускаются, если первый нашёл заголовок таблицы и не менее восьми уверенных строк без спорных, а на каждой странице прочитал оценки или распознал обложку приложения с номером. Оценки ниже порога показываются предварительно и требуют сверки; среднее публикуется, когда приняты все строки. Если оценку не смог прочитать ни один OCR, поле остаётся пустым. Уверенность OCR не гарантирует полноту списка: пропущенную целиком строку автоматическое правило не обнаружит.

Средний балл принятых оценок появляется сразу в карточках и выгрузке. Если категория определена, все найденные оценки приняты, а прочитанные серию и номер не противоречат друг другу, документ принимается автоматически. Отсутствие серии или номера не блокирует расчёт и принятие; пустые поля остаются пустыми. При расхождении найденных реквизитов нужна их сверка. Правка оценки или списка предметов снимает автоматическое подтверждение и требует подтверждения проверки документа.

Для запуска в Windows:

```powershell
.\start.ps1
# Другой свободный порт:
.\start.ps1 -Port 8770
```

Окружение OCR и Docling — `.ocr-venv`, модели — `.ocr-models`. Существующая `.venv` сохранена. Для переустановки на Windows нужны Python 3.12 и Node.js; выполните `setup_ocr.ps1`. Скрипт также скачает модели структуры Docling. Интернет используется только при подготовке зависимостей и весов. Во время распознавания автоматическая загрузка весов и внешние сервисы отключены, документы остаются на компьютере. Если Docling не установлен, обычный OCR продолжит работу, а сложные таблицы останутся для ручной проверки.

На macOS и Linux установите Python 3.12 и Node.js, затем один раз запустите `sh setup_ocr.sh`. На macOS `start.command` использует подготовленное `.ocr-venv`. Первая установка Docling и моделей может занять заметное время; повторные запуски не скачивают модели заново.

Дополнительные OCR и Docling работают через `server.py`. Автономная статическая сборка `dist` работает без Python и использует один Tesseract.js: строки от 80% принимаются, остальные требуют ручной сверки. Docling в браузерной версии не используется.

Ускорение: при запуске сервер прогревает OCR, затем Docling на учебном образце. Готовность видна в `/api/health` через `ocr_ready` и `docling_ready`; дождитесь `docling_ready: true` перед обработкой сложных таблиц. Модели остаются загруженными до остановки сервера; Tesseract читает до двух страниц параллельно, дополнительное изображение готовится только для повторного чтения заголовка. PDF с одним полноразмерным изображением исходного разрешения до 180 dpi выводятся в 200 dpi; другие PDF — до 300 dpi. После обновления перезапустите server.py. Это ускорение относится к локальному режиму.

При согласованном типе и номере диплома (или согласованном типе достижения) локальный режим не запускает EasyOCR ради отсутствующей таблицы школьных оценок. Если OCR расходятся по оценкам или не достигают порога, повторное чтение сохраняется. В браузерной версии Tesseract остаётся загруженным ещё 90 секунд после обработки пакета, чтобы следующая загрузка не ждала повторной инициализации; затем память освобождается.
