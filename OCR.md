Локальный сервер сначала читает сканы через Tesseract. Docling подключается для отдельных страниц, на которых не удалось уверенно разобрать таблицу, определить тип документа или прочитать реквизиты обложки. Внутри Docling текст читает RapidOCR.

На скане таблицы Tesseract должен найти не менее восьми уверенных строк для пропуска Docling. Непривязанные оценки, неуверенные строки таблицы и сомнительные реквизиты обложки запускают повторное чтение. Если Tesseract уверенно распознал обложку по заголовку и тексту выдачи или дате рождения, отсутствие номера само по себе не запускает Docling. Если нужный повторный проход по таблице не удался, страница остаётся на ручной проверке. Список страниц, отправленных в Docling, сохраняется в `ocr.fallback_pages`.

Для автоматического принятия оценки нужен уверенный результат хотя бы одного OCR без уверенного противоречия. Структурная подсказка Docling без оценки уверенности требует ручной сверки. На каждой странице программа ищет оценку или признаки страницы без оценок, например титульный текст и реквизиты обложки. Страницы, которые не удалось отнести ни к одной из этих групп, перечисляются в `ocr.incomplete_pages`. Средний балл появляется после ручного подтверждения сверки этих страниц. Уверенность OCR не гарантирует полноту перечня предметов.

Средний балл принятых оценок появляется сразу в карточках и выгрузке. Если категория определена, все найденные оценки приняты, а прочитанные серию и номер не противоречат друг другу, документ принимается автоматически. Отсутствие серии или номера не блокирует расчёт и принятие; пустые поля остаются пустыми. При расхождении найденных реквизитов нужна их сверка. Правка оценки или списка предметов снимает автоматическое подтверждение и требует подтверждения проверки документа.

Для запуска в Windows:

```powershell
.\start.ps1
# Другой свободный порт:
.\start.ps1 -Port 8770
```

Окружение OCR и Docling — `.ocr-venv`, модели — `.ocr-models`. Существующая `.venv` сохранена. Для переустановки на Windows нужны Python 3.12 и Node.js; выполните `setup_ocr.ps1`. Скрипт также скачает модели структуры Docling. Интернет используется только при подготовке зависимостей и весов. Во время распознавания автоматическая загрузка весов и внешние сервисы отключены, документы остаются на компьютере.

На macOS и Linux установите Python 3.12 и Node.js, затем один раз запустите `sh setup_ocr.sh`. На macOS `start.command` использует подготовленное `.ocr-venv`. Первая установка Docling и моделей может занять заметное время; повторные запуски не скачивают модели заново.

При запуске Tesseract и Docling распознают учебный образец. Сайт открывается и API начинает отвечать после успешного прогрева обоих движков. Если прогрев не удался, в терминале появится название движка и команда для подготовки окружения. В статической версии на GitHub Pages работает Tesseract.js с тем же порогом 80%.

Для PDF с готовым текстом локальный сервер читает текст напрямую, если на странице нет растровых изображений и приложение распознало нужные поля. Для сканов и неоднозначных страниц используется обычный OCR. В смешанном PDF способ обработки выбирается для каждой страницы.

Для разбора структуры страниц установщик загружает Docling Heron в формате Safetensors и TableFormer Fast. Для чтения русского текста RapidOCR использует три отдельные модели ONNX из каталога `.ocr-models/rapid`.

В выгрузке JSON поле `ocr.pdf_text_pages` показывает страницы, прочитанные из текста PDF. В `ocr.timing_seconds` указано время в секундах на подготовку страниц, Docling, Tesseract, сбор результата и всю обработку на сервере. Время загрузки файла браузером и ожидания в очереди сюда не входит.
