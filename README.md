# Приём · Обработка документов

Приложение для распознавания сканов документов абитуриентов с проверкой результатов и выгрузкой в JSON/CSV.

**Сайт:** https://ogyod.github.io/Algoritmi/

Поддерживает аттестаты за 9 и 11 классов, дипломы СПО, бакалавриата, специалитета, магистратуры и аспирантуры. Извлекает серию и номер; для аттестатов распознаёт оценки и рассчитывает средний балл. Паспорта не обрабатываются.

## Использование

1. Загрузите PDF, JPG, PNG, TIFF или WEBP.
2. Выберите категорию или автоматическое определение и запустите распознавание.
3. Сверьте реквизиты и оценки со сканом, исправьте ошибки и подтвердите проверку.
4. Скачайте JSON или CSV.

Сайт работает на GitHub Pages. Распознавание и разбор документов выполняются в браузере, файлы не отправляются на сервер. Для первого запуска нужен интернет, чтобы загрузить обработчики и языковые модели. Результаты хранятся в памяти вкладки до обновления страницы. Для импорта CSV в Excel задайте серии и номеру текстовый тип, чтобы сохранить начальные нули.

Справочник `subjects.json` содержит 70 названий предметов и их сокращения. Неизвестные названия из распознанной таблицы оценок сохраняются для ручной проверки. Нечитаемые и противоречивые оценки требуют исправления перед расчётом среднего балла.

В `samples/` находятся только искусственные учебные образцы.

## Локальный запуск

Нужны Python 3.10+ и Node.js 22+.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
npm install --ignore-scripts
python server.py
```

Откройте http://127.0.0.1:8765. Остановка сервера — Ctrl+C.

В Windows используйте `python -m venv .venv` и `.venv\Scripts\activate` для создания и активации окружения. На macOS также можно запустить `zsh start.command`.

Для установки Node-зависимостей по включённому файлу фиксации версий: `pnpm install --frozen-lockfile --ignore-scripts`.

Локальный сервер использует тот же разборщик документов, что и сайт. Модели языков включены в `.models/`.

## Публикация и проверки

Обновления ветки `main` автоматически проходят проверки и публикуются через GitHub Actions. В настройках репозитория Pages должен быть выбран источник GitHub Actions.

```sh
python -m unittest discover -s tests -p 'test_*.py'
npm test
npm run build
```

Собранная версия сайта находится в `dist/`.
