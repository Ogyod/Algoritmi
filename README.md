# Algoritmi

Локальная обработка сканов аттестатов, дипломов и достижений. Оценки с уверенностью OCR от 80% принимаются автоматически; при слабом результате подключаются дополнительные распознаватели. Docling помогает разобрать сложную таблицу, а его предложения проверяются по скану. Подробности — в [OCR.md](OCR.md).

## Windows

Установите Python 3.12 и Node.js. В папке проекта один раз подготовьте зависимости и модели:

```powershell
.\setup_ocr.ps1
```

Затем запускайте приложение командой `.\start.ps1`.

## macOS и Linux

Установите Python 3.12 и Node.js, затем один раз выполните `sh setup_ocr.sh`. Для полного OCR на macOS нужен Mac с Apple Silicon. На macOS откройте `start.command`; на Linux запустите `.ocr-venv/bin/python server.py --open`.

Локальная страница откроется на `http://127.0.0.1:8765`. При обработке файлы остаются на компьютере. Статическая версия сайта работает в браузере с одним OCR и принимает оценки с уверенностью от 80%; остальные строки требуют сверки.

## Где править код

| Задача | Файлы |
| --- | --- |
| Маршруты HTTP и формат запросов | `server.py`, `http_uploads.py` |
| Подготовка страниц PDF и изображений, предпросмотр | `document_processing.py` |
| Порядок запуска OCR, порог и выбор оценок | `ocr_engines.py`, `ocr_consensus.py`, `ocr_adapter.py` |
| Категории документов и извлечение реквизитов | `core.py`, `subjects.json` |
| Очередь и хранение пакетов, правила ручной сверки API | `batch_service.py`, `document_review.py` |
| Интерфейс, ручная сверка и экспорт | `static/app.js`, `static/domain.js` |
| Связь интерфейса с сервером и браузерный OCR | `static/processor.js`, `static/browser-processor.js`, `static/parser-worker.js` |

Локальный сервер и API используют общую обработку страниц. Браузерная версия запускает тот же `core.py` через Pyodide. После правок браузерной версии выполните `npm run build`. Описание маршрутов и полей API находится в [docs/API.md](docs/API.md).
