# Algoritmi

Локальная обработка сканов аттестатов, дипломов и достижений. Два независимых OCR сверяют оценки; при расхождениях подключается третий. Docling помогает разобрать сложную таблицу, а его предложения проверяются по скану. Подробности — в [OCR.md](OCR.md).

## Windows

Установите Python 3.12 и Node.js. В папке проекта один раз подготовьте зависимости и модели:

```powershell
.\setup_ocr.ps1
```

Затем запускайте приложение командой `.\start.ps1`.

## macOS и Linux

Установите Python 3.12 и Node.js, затем один раз выполните `sh setup_ocr.sh`. Для полного OCR на macOS нужен Mac с Apple Silicon. На macOS откройте `start.command`; на Linux запустите `.ocr-venv/bin/python server.py --open`.

Локальная страница откроется на `http://127.0.0.1:8765`. При обработке файлы остаются на компьютере. Статическая версия сайта работает в браузере с одним OCR и требует ручной сверки оценок.

## Обновление

Если репозиторий клонирован через Git, выполните `git pull --ff-only origin main`. Если ранее вы добавили этот репозиторий под именем `upstream`, используйте `git pull --ff-only upstream main`. После обновления повторите команду подготовки моделей для вашей системы.
