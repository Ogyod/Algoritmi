# Приём · Обработка документов

Локальное приложение для распознавания сканов документов абитуриентов с проверкой результатов и выгрузкой в JSON/CSV.

Поддерживает аттестаты за 9 и 11 классов, дипломы СПО, бакалавриата, специалитета, магистратуры и аспирантуры. Извлекает серию и номер, для аттестатов распознаёт оценки и рассчитывает средний балл. Доступ к сайту приёмной комиссии не требуется.

## Запуск

Нужны Python 3.10+ и Node.js 18+.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
npm install --ignore-scripts
python server.py
```

Откройте http://127.0.0.1:8765. Остановка сервера — Ctrl+C.

В Windows используйте `python -m venv .venv` и `.venv\Scripts\activate` для создания и активации окружения. На macOS также можно запустить `zsh start.command`.

Для установки Node-зависимостей по включённому файлу фиксации версий: `pnpm install --frozen-lockfile --ignore-scripts`.

## Использование

1. Загрузите PDF, JPG, PNG, TIFF или WEBP.
2. Выберите категорию или автоматическое определение и запустите распознавание.
3. Сверьте реквизиты и оценки со сканом, исправьте ошибки и подтвердите проверку.
4. Скачайте JSON или CSV.

Распознавание выполняется на компьютере. Модели языков включены в `.models/`. Результаты хранятся в памяти вкладки до обновления страницы. Для импорта CSV в Excel задайте серии и номеру текстовый тип, чтобы сохранить начальные нули.

В `samples/` находятся только искусственные учебные образцы.
